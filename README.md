# webcollection

A collection of animated single-page websites. Each one is a self-contained `index.html`; open it in a browser, no build step.

| Site | Folder |
| --- | --- |
| Brightwell Dental Care: dental clinic with floating bubbles, FDI tooth chart, whitening shade slider, booking | [`brightwell-dental/`](brightwell-dental/) |
| Northbar Strength Club: gym with animated barbell, moving background, class schedule, plate calculator | [`northbar-gym/`](northbar-gym/) |

Names, prices, addresses and reviews are placeholders. Forms are demos and don't send anything.

To publish with GitHub Pages: Settings → Pages → Deploy from branch `main`, folder `/ (root)`.
